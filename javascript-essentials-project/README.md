# JavaScript Essentials 1: Modules 2 and 3

**Student:** Qiyaam Moodley  
**Project:** Combined Module 2 and Module 3 challenges

## Files
- `qiyaam-moodley-module2-3.js`: Challenges 1-9 and 11-12, including comments, test cases, calculations and reflection.
- `challenge10.html`: Browser-based alert, prompt and confirm interaction flow.

## How to run
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run `node qiyaam-moodley-module2-3.js`.
4. Open `challenge10.html` in a browser to test Challenge 10.

The project uses simple examples and explanatory comments. Financial examples are educational demonstrations, not official payroll or banking advice. Real payroll tax and banking systems use current rules and money-safe decimal representations.
